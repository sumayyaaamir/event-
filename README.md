# HackFusion 2026 - Event Portal

A responsive single-page web application built for the **HackFusion 2026** university hackathon event.

## Features
- **Event Overview & Tracks:** Highlights Cloud & DevOps, Applied AI, and Cybersecurity tracks.
- **Live Schedule:** Displays key milestones across the 36-hour sprint.
- **Team Registration Form:** Interactive client-side registration workflow.

## Deployment
Can be hosted statically via GitHub Pages, Nginx, or inside a lightweight Docker container (`nginx:alpine`).
